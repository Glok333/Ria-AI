# Ріас — локальний ІІ-компаньйон для Windows

🇺🇦 Українська · [🇬🇧 English](README_EN.md)

**Ріас** — аніме-помічниця, яка живе на робочому столі. Натискаєш **Ctrl+Alt+X**, вона з'являється з бабл-відповіддю й полем вводу, а ти пишеш їй українською чи російською. Вона відкриває програми й сайти, створює файли та код, а її поза змінюється залежно від того, чим вона зайнята: чекає, думає чи відповідає.

Уся «розумна» частина працює **локально на твоєму ПК** через [Ollama](https://ollama.com): без API-ключів, без підписок, без відправки твоїх повідомлень у хмару.

> Проєкт створено за допомогою **Claude** (Anthropic): код і документацію написав ШІ-асистент у діалозі з автором, який придумував ідею, тестував і доводив результат.

---

## Можливості

- **Виклик гарячою клавішею.** Ctrl+Alt+X показує й ховає Ріас. Вікно без рамки, завжди поверх інших, його можна тягати мишкою де завгодно.
- **Спілкування українською та російською** у вигляді коміксного бабла. Текст відповіді можна виділяти й копіювати (Ctrl+C або права кнопка мишки).
- **Характер.** Ріас розмовляє як аристократична, тепла й трохи грайлива помічниця, яка охоче виконує твої прохання. Характер задається текстом у коді, і його легко змінити.
- **Пози.** Окремі картинки для станів «чекає», «думає», «говорить» (у «говорить» два кадри чергуються).
- **Відкриття програм і сайтів** зі списку, який ти контролюєш. Нові програми Ріас додає в список сама за твоїм проханням, але тільки після твого підтвердження у вікні.
- **Файли й код.** Створює, читає й показує файли в окремій робочій папці `workspace`. Може запустити `.py` файл, але лише після твого підтвердження.

## Встановлення

**1. Встанови Python.** Завантаж з [python.org/downloads](https://www.python.org/downloads/). Під час установки **обов'язково постав галочку «Add python.exe to PATH»**. Перевір у PowerShell: `python --version` (має бути 3.10+).

**2. Встанови Ollama** з [ollama.com/download](https://ollama.com/download) і запусти його (значок з'явиться в треї біля годинника).

**3. Завантаж модель** у PowerShell:

```
ollama pull qwen3:4b-instruct
```

Це приблизно 2.5 ГБ. Саме версію `-instruct`: вона відповідає одразу. Звичайний `qwen3:4b` спершу довго «міркує», і Ріас відповідала б по 8–10 секунд.

**4. Завантаж цей репозиторій:** кнопка **Code → Download ZIP**, розпакуй у будь-яку папку (наприклад, `C:\Ria`). Або через git:

```
git clone https://github.com/Glok333/Ria-AI.git
cd Ria-AI
```

**5. Встанови бібліотеки.** У PowerShell відкрий папку з проєктом (`cd C:\Ria`) і виконай:

```
pip install -r requirements.txt
```

Якщо `pip` не знайдено, виконай `python -m pip install -r requirements.txt`.

## Запуск

Переконайся, що Ollama працює (значок у треї), і запусти:

```
python ria.py
```

або двічі клацни `start.bat`. З'явиться Ріас із привітанням. Далі натискай **Ctrl+Alt+X**, щоб сховати чи показати її.

> Перша відповідь після запуску може йти довше, бо модель завантажується в пам'ять. Далі працює швидко.

## Налаштування

Усе налаштовується на початку файлу `ria.py`, у блоці `НАЛАШТУВАННЯ`:

| Що | Де |
|---|---|
| Модель для чату | `CHAT_MODEL`. Підійде будь-яка модель Ollama з підтримкою інструментів (на її сторінці в бібліотеці є позначка *tools*). Моделі з режимом «міркування» відповідають повільніше |
| Окрема модель для коду | `CODE_MODEL`, наприклад `"qwen2.5-coder:7b"` (не забудь її завантажити). Порожній рядок вимикає |
| Гаряча клавіша | `HOTKEY` |
| Програми | словник `APPS`; додані через чат програми зберігаються в `apps.json` |
| Характер | `SYSTEM_PROMPT` |
| Картинки | файли `ria_idle.png`, `ria_thinking.png`, `ria_speaking.png`, `ria_speaking2.png` поруч зі скриптом (усі **одного розміру**, краще PNG із прозорим фоном). Якщо їх немає, береться `ria.png`, а якщо й цього немає, показується заглушка (•ᴗ•) |

Робоча папка `workspace` і файл `apps.json` створюються поруч зі скриптом автоматично.

## Безпека

- Усе працює локально. Єдиний мережевий запит програма робить до твого ж Ollama (`localhost`). Браузер відкривається лише коли ти просиш відкрити сайт.
- Ріас може відкривати **тільки програми зі списку** `APPS`. Додати нову можна лише після підтвердження у вікні (приймаються `.exe`, `.lnk`, `.url`).
- Файли створюються й читаються **тільки в папці `workspace`**, вийти за її межі не можна.
- Запуск `.py` файлів потребує підтвердження, і виконується не довше 30 секунд. Але код у файлі виконується з твоїми правами, тому читай його у вікні підтвердження перед тим, як натиснути «Так».
- Бібліотека `keyboard` підписується на глобальні події клавіатури, щоб ловити гарячу клавішу. Код програми реагує лише на Ctrl+Alt+X і нічого не записує. Це можна перевірити в `ria.py` (функція `run`). Окремі антивіруси можуть насторожитися через такий тип бібліотек.

## Проблеми й рішення

| Проблема | Рішення |
|---|---|
| «Ollama не запущений» | Запусти Ollama з меню «Пуск», значок має з'явитися в треї |
| `pip` / `python` не знайдено | Перевстанови Python із галочкою «Add python.exe to PATH» або використовуй `py -m pip ...` і `py ria.py` |
| Модель не знаходиться при `ollama pull` | Перевір актуальну назву на [ollama.com/library](https://ollama.com/library) і постав її в `CHAT_MODEL` |
| Відповіді дуже повільні | Перевір командою `ollama ps`, що в колонці PROCESSOR написано GPU, і що використовується `-instruct` модель, а не «міркуюча» |
| У бабл потрапляє англійський текст «роздумів» | Ти використовуєш модель із режимом міркування, перейди на `qwen3:4b-instruct` |
| Ctrl+Alt+X не реагує | У деяких іграх у повноекранному режимі гарячі клавіші перехоплюються. Спробуй віконний режим гри або іншу комбінацію в `HOTKEY` |
| Дуже малі моделі плутають інструменти | Повтори запит точніше, або спробуй більшу модель |

## Обмеження

- Лише Windows (використовує `os.startfile` і прозорість вікна Windows).
- Модель 4B невелика: вона може помилятися, плутати інструменти й слабко пише складний код.
- Поки що **без зору**: вона не бачить екран і не керує мишкою та клавіатурою.
- Пози — це нахили голови однієї картинки, а не повноцінна анімація. Для живої анімації потрібна модель Live2D (у планах).
